💱 Currency Converter

A simple and responsive Currency Converter built using HTML, CSS, and JavaScript.
This project converts one currency into another using real-time exchange rates from an API.

🚀 Features
Convert currencies instantly
Real-time exchange rates
Supports multiple currencies
Swap currencies option
Responsive and clean UI
🛠️ Technologies Used
HTML
CSS
JavaScript
Exchange Rate API
📂 Project Structure
currency-converter/
│
├── index.html
├── style.css
└── script.js
▶️ How to Run
Download or clone the project
Open the project folder
Open index.html in your browser
💡 How It Works
User selects two currencies
User enters an amount
JavaScript fetches live exchange rates using API
Converted amount is displayed instantly
